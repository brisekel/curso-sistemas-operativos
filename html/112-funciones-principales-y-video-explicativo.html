1.1.2 Funciones Principales del Sistema Operativo

El Sistema Operativo (SO) actúa como el administrador central del equipo. Para garantizar que los programas funcionen de forma fluida y sin conflictos, realiza cuatro funciones fundamentales:

1. Gestión de Procesos (CPU)

Un proceso es un programa en ejecución. El Sistema Operativo se encarga de:

  • Planificar: Decidir qué programa utiliza el procesador y durante cuánto tiempo.
  • Sincronizar: Evitar que dos programas intenten usar el procesador al mismo tiempo provocando un bloqueo.
  • Finalizar: Cerrar de manera limpia las aplicaciones cuando el usuario las termina o cuando fallan.

2. Gestión de la Memoria Principal (RAM)

La memoria RAM es el espacio donde se guardan temporalmente los datos en uso. El SO realiza:

  • Asignación: Reserva bloques de memoria RAM para cada aplicación cuando se abre.
  • Protección: Garantiza que una aplicación no invada ni modifique el espacio de memoria reservado para otra.
  • Liberación: Recupera el espacio en RAM inmediatamente cuando una aplicación se cierra.

3. Gestión de Almacenamiento y Archivos

Organiza la información almacenada de forma permanente en discos duros o unidades SSD:

  • Estructura jerárquica: Organiza la información en carpetas, directorios y archivos.
  • Control de acceso: Define permisos (lectura, escritura, ejecución) para proteger los archivos.
  • Operaciones básicas: Administra la creación, lectura, modificación y eliminación de datos.

4. Gestión de Entrada / Salida (E/S) y Periféricos

Permite la comunicación entre el software y los dispositivos físicos externos:

    • Uso de Controladores (Drivers): Traduce las órdenes del sistema operativo a un lenguaje que el hardware (impresoras, teclados, tarjetas de red) pueda entender.
    • Memoria Intermedia (Buffering): Mantiene datos temporalmente mientras se transfieren entre dispositivos con diferentes velocidades de trabajo.
