1.1.1 Concepto y Rol del Sistema Operativo

Sistema Operativo

¿Qué es un Sistema Operativo? Un Sistema Operativo (SO) es el programa de software fundamental que gestiona los recursos de hardware de una computadora y proporciona servicios esenciales a las aplicaciones del usuario. Actúa como un intermediario directo entre el usuario, las aplicaciones y el hardware físico de la máquina. 

Arquitectura de Intermediación (Estratificación por Capas):

  • Usuario: Interactúa con el sistema mediante interfaces gráficas (GUI) o líneas de comandos (CLI).
  • Software de Aplicación: Programas como navegadores web, procesadores de texto o gestores de bases de datos.
  • Sistema Operativo / Kernel: Administra la memoria, controla los procesos y gestiona las llamadas al sistema.
  • Hardware: Componentes físicos (CPU, Memoria RAM, Discos de Almacenamiento, Dispositivos E/S).
